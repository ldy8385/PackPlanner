계정 및 데이터 삭제

앱에서 계정 삭제하기

PackPlanner 앱 내에서 직접 계정을 삭제할 수 있습니다.

  1. PackPlanner 앱을 실행합니다.
  2. 하단 탭에서 마이페이지를 선택합니다.
  3. 계정 삭제 버튼을 탭합니다.
  4. 확인 팝업에서 삭제를 선택합니다.

주의: 계정을 삭제하면 모든 데이터가 영구적으로 삭제되며, 이 작업은 되돌릴 수 없습니다.

삭제되는 데이터

계정 삭제 시 다음 데이터가 모두 삭제됩니다.

  • 계정 정보 (이메일, 이름, 프로필 사진)
  • 캠핑 계획 데이터
  • 장비 목록 데이터
  • 템플릿 데이터

문의

앱에 로그인할 수 없거나 기타 문의사항이 있는 경우, 아래 이메일로 계정 삭제를 요청하실 수 있습니다.
